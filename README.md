# QuestDay 2.0

Telegram Mini App для ежедневных задач в стиле RPG.

## Что исправлено и добавлено

- Рабочее создание собственных квестов.
- XP, уровни и плавно растущая стоимость следующего уровня.
- 4 характеристики: сила, интеллект, выносливость, дисциплина.
- Серия дней и максимальная серия.
- Календарь с состояниями: есть квесты / частично выполнено / всё выполнено.
- 12 достижений с сохранением даты получения и наградой XP.
- Быстрые готовые квесты.
- Защита от дублей квестов на одну дату.
- Telegram WebApp SDK и автоматическое определение языка пользователя.
- Имя пользователя Telegram отображается в приложении.
- Локальное сохранение как fallback.
- Экспорт и сброс прогресса.
- Опциональная серверная синхронизация через Vercel Function + Redis REST.
- Проверка подписи Telegram `initData` на сервере перед чтением/записью профиля.

## Деплой на Vercel

1. Залить содержимое проекта в GitHub.
2. Подключить репозиторий к Vercel.
3. Для облачного сохранения подключить Redis REST и добавить Environment Variables:
   - `KV_REST_API_URL`
   - `KV_REST_API_TOKEN`
   - `TELEGRAM_BOT_TOKEN`
4. Redeploy.

Без этих переменных Mini App всё равно работает, но хранит прогресс локально.

## Telegram

В настройках бота укажи URL задеплоенного Mini App. Внутри Telegram приложение получает `initData`; сервер проверяет подпись перед использованием Telegram ID.
